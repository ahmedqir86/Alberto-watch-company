# Alberto Watch Company — Aptech eProject

Responsive single-page educational website. Required functionality: categories and product listing, product detail popup, prices, gallery, technology, store locator, support, about, contact, site map, visitor counter, navigation effects, live date/time/location ticker.

**Only additional functionality:** Contact form validation (name 3+ letters, email 3+ letters before @gmail.com, @yahoo.com or @outlook.com, subject required, message 10+ letters).

## Run
Extract ZIP and open `index.html` in a browser. JSON has a JavaScript fallback for file:// mode. For local testing, VS Code Live Server is recommended. Google Maps and geolocation may require internet and browser permission.

## Images
All 15 product images are stored locally under `assets/images/products/hand-watches`, `smart-watches`, and `wall-clocks`. The seven hand-watch images are individually cropped AI-generated Alberto-style watch concept photographs, **not official Alberto product photographs**. Original online photo links were removed from active catalogue so products work offline.

## Notes
Prices are illustrative student-project prices. Contact form validates, shows a success message and resets; it does not submit to a backend. Product details open in a popup as specified by the eProject.
